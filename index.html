Getting a model file out of Studio
  1. Select your Model in the Explorer.
  2. Right-click → Save to File… (or Export Selection).
  3. Drop the .rbxm / .rbxmx here.

    
Getting your model into Studio
  1. Build it on the Code → Model tab and download the .rbxmx.
  2. In Studio, right-click Workspace → Insert from File…
  3. Or paste the code into a Script / the command bar and run it.

    
Good to know
  • MeshPart meshes & union shapes can't be rebuilt by scripts — they're kept as placeholders.
  • Setting .Source only works from the command bar or plugins.
  • Most Luau syntax works; if-then-else expressions and generics aren't supported in Code → Model.
  • Everything runs locally in your browser — files are never uploaded.
